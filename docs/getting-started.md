# Getting started

1. Start the stack: `docker compose up -d`. Details, including using services you already run, are in the [README](../README.md).
2. Open http://localhost:3000 and create the first account. It is the administrator.
3. Add an indexer under Settings > Search sources (one click for public ones). Without one nothing can download. The checklist on the Home page shows what is still missing.
4. Open Search, find a title and request it. Pick the quality you want in the dropdown next to the request button.
5. Watch it appear in Requests, then Downloads, then your library.

Already have movies, shows or music on your computer? Point the library at those folders instead of starting empty: [using the media you already have](existing-media.md).

To let other people in, add accounts under Settings > People and requests, and turn on sign-up there too, and share the address shown there.

Developing instead? See [development](development.md).
